📋 The Canonical CS 6515 5-Part Grading Rubric

Warning: CS6515 graders follow this strict template. Leaving out a component or writing pseudocode when an algorithmic narrative is required causes severe point penalties.

1. Subproblem Definition

High Penalty Trap
What Graders Demand:

Must describe in plain English what table entry T(i) or T(i, j) represents. Specify exact prefix/suffix, 1-based indexing, and state bounds.

Example (LIS):

"Let L(i) be the length of the longest increasing subsequence of A[1 \dots i] that must include A[i] as its last element, for 1 \le i \le n."

2. Recurrence Relation

Core Math
What Graders Demand:

Express T(i, j) strictly as a function of strictly smaller subproblems. Explicitly explain the meaning of each branch in the \min / \max.

Common Trap:

Forgetting boundary conditions in the recurrence or mixing 0-indexed and 1-indexed pointers.

3. Base Cases

Easy -2 to -4 Points
What Graders Demand:

Define all initial boundary values (e.g. i=0 or empty sequence). State whether unreachable states are initialized to 0, -\infty, or +\infty.

Example (Knapsack):

K(0, w) = 0 for all 0 \le w \le W, and K(i, 0) = 0 for all 0 \le i \le n.

4. Fill Order & Algorithm

No Pseudocode
What Graders Demand:

Explain the bottom-up loop structure. State the loop directions (e.g. "outer loop i = 1 \dots n, inner loop w = 1 \dots W") ensuring dependencies are calculated before being used.

Goal Extraction:

Explicitly identify where the final answer is located (e.g. K(n, W) or \max_{1 \le i \le n} L(i)).

5. Runtime & Space Complexity Analysis

Formula Required

Always state the formula: Total Time = (# of table entries) × (time to compute one entry) + (reconstruction/post-processing time).

Always separately provide the Space Complexity: table dimensions O(n \cdot W) or O(n^2).

⚡ Exam 1 Mastery: DP Archetypes & Divide-and-Conquer

Weeks 1–4 · Modules DP1, DP2, DC3, DC1, DC2, DP3. Master these 7 DP archetypes and recurrence patterns.

1. Longest Increasing Subsequence (LIS)

1-Index Suffix
Subproblem:

L(i): length of LIS in A[1 \dots i] ending at and including A[i].

Recurrence:
L(i) = 1 + \max(\{0\} \cup \{L(j) : 1 \le j < i \text{ and } A[j] < A[i]\})
Final Answer & Runtime:

Goal: \max_{1 \le i \le n} L(i). Table size: n. Time: O(n^2). Space: O(n).

2. Longest Common Subsequence (LCS)

2-Prefix DP
Subproblem:

C(i, j): length of LCS of prefixes X[1 \dots i] and Y[1 \dots j].

Recurrence:
C(i, j) = \begin{cases} C(i-1, j-1) + 1 & \text{if } X[i] = Y[j] \\ \max(C(i-1, j), C(i, j-1)) & \text{if } X[i] \neq Y[j] \end{cases}
Final Answer & Runtime:

Goal: C(m, n). Base: C(i, 0) = C(0, j) = 0. Time: O(mn). Space: O(mn).

3. 0/1 Knapsack (Without Repetition)

Subset Capacity
Subproblem:

K(i, w): max value using a subset of items 1 \dots i with max weight capacity w.

Recurrence:
K(i, w) = \begin{cases} K(i-1, w) & \text{if } w_i > w \\ \max(K(i-1, w), K(i-1, w - w_i) + v_i) & \text{if } w_i \le w \end{cases}
Final Answer & Runtime:

Goal: K(n, W). Base: K(0, w) = K(i, 0) = 0. Time: O(nW) (pseudo-polynomial).

4. Unbounded Knapsack (With Repetition)

1D Capacity
Subproblem:

K(w): max value achievable with total weight capacity w.

Recurrence:
K(w) = \max(\{0\} \cup \{K(w - w_i) + v_i : i \text{ such that } w_i \le w\})
Final Answer & Runtime:

Goal: K(W). Base: K(0) = 0. Time: O(nW). Space: O(W).

5. Chain Matrix Multiplication

Interval DP
Subproblem:

C(i, j): min scalar multiplications to multiply matrices A_i \times \dots \times A_j.

Recurrence:
C(i, j) = \min_{i \le k < j} \{ C(i, k) + C(k+1, j) + m_{i-1} m_k m_j \}
Fill Order & Runtime:

Loop by interval length L = 2 \dots n. Base: C(i, i) = 0. Time: O(n^3). Space: O(n^2).

6. Shortest Path in a DAG

Topological DP
Subproblem:

dist(u): length of shortest path from source s to vertex u.

Recurrence:
dist(u) = \min_{(v, u) \in E} \{ dist(v) + w(v, u) \}
Fill Order & Runtime:

Process vertices in topological sort order. Base: dist(s)=0, all others \infty. Time: O(V + E).

Master Theorem Decision Tree

For divide-and-conquer recurrences of form: T(n) = a T(n/b) + O(n^d), where a \ge 1, b > 1, d \ge 0:

Condition Intuition Solution Runtime Canonical Example
d < \log_b a Leaf-heavy: Leaves dominate cost O(n^{\log_b a}) Karatsuba Multiply: T(n) = 3T(n/2) + O(n) \implies O(n^{1.585})
d = \log_b a Balanced: Each level costs the same O(n^d \log n) MergeSort: T(n) = 2T(n/2) + O(n) \implies O(n \log n)
d > \log_b a Root-heavy: Top level dominates cost O(n^d) T(n) = 2T(n/2) + O(n^2) \implies O(n^2)

🕸️ Exam 2 Mastery: Graph Algorithms & Network Flow

Weeks 4–7 · Modules GR1, GR2, GR3, MF1, MF2, MF4. Graph reductions, cut property, and residual networks.

Kosaraju Strongly Connected Components

O(V + E)
Two-Pass Algorithm:

1. Run DFS on reversed graph G^R, recording post-visit numbers.

2. Run DFS on original graph G, visiting unvisited vertices in decreasing order of post-numbers.

Key Theorem:

Vertex with largest post-number in G^R belongs to a source SCC in G^R, which is a sink SCC in G. Peeling off sink SCCs isolates components cleanly.

2-SAT via SCC Decomposition

O(V + E)
Implication Graph Construction:

Convert clause (x \lor y) into two implication edges: \neg x \to y and \neg y \to x. Graph has 2n vertices.

Satisfiability Rule:

A 2-SAT instance is satisfiable if and only if no variable x and its negation \neg x lie in the same SCC.

Assignment Rule:

Contract SCCs to DAG. Assign truth values by traversing in reverse topological order (sink to source): first seen gets TRUE, its negation gets FALSE.

MST Cut Property & Cycle Property

Greedy Proofs
The Cut Property (Kruskal & Prim):

For any cut (S, V \setminus S), the edge of minimum weight crossing the cut is guaranteed to be in the MST.

The Cycle Property:

In any cycle C, the edge of maximum weight is never in the unique MST (safe to eliminate).

Max-Flow Min-Cut Theorem & Edmonds-Karp

MF Duality
Residual Graph G_f Edges:

Forward edge (u, v) has residual capacity c(u,v) - f(u,v).

Backward edge (v, u) has residual capacity f(u,v) (pushing backwards cancels flow).

Min-Cut Extraction:

When no augmenting path exists, let S = \{u \in V : u \text{ reachable from } s \text{ in } G_f\}. The cut (S, V \setminus S) is a minimum cut with capacity equal to max flow!

Edmonds-Karp Runtime:

O(V \cdot E^2) using BFS to find augmenting path with fewest edges.

🧩 Exam 3 Mastery: NP-Completeness & Linear Programming

Weeks 8–10 · Modules NP1–NP5, LP1–LP4. Reduction directions, standard form, and duality.

⚠️ The Golden Rule of NP-Completeness Reductions

Exam Zero-Credit Trap

To prove problem B is NP-Complete:

  1. Show B \in \text{NP}: Given a proposed certificate/solution, verify it in polynomial time.
  2. Choose a known NP-Complete problem A.
  3. Reduce A \le_p B: Construct a polynomial-time algorithm f mapping an arbitrary instance I_A \to I_B.
  4. Correctness: Prove I_A is YES \iff f(I_A) is YES (both directions: \implies and \impliedby).

Fatal Mistake: NEVER reduce B \le_p A! That only proves B is no harder than A, not that B is NP-hard.

Independent Set ↔ Vertex Cover

Complement Theorem
Equivalence:

In any graph G=(V, E), a subset S \subseteq V is an Independent Set of size k \iff the complement V \setminus S is a Vertex Cover of size |V| - k.

Reduction:

Given instance (G, k) of IS, create instance (G, |V| - k) of VC. Construction takes O(1) time.

Independent Set ↔ Clique

Complement Graph
Equivalence:

A subset S \subseteq V is an Independent Set in G=(V,E) \iff S is a Clique in the complement graph \overline{G}=(V, \overline{E}).

Reduction:

Construct complement graph \overline{G} where (u, v) \in \overline{E} \iff (u, v) \notin E. Runtime: O(V^2).

Linear Programming Duality Recipes

Primal ↔ Dual
Standard Primal-Dual Recipe:
Primal (Maximization) Dual (Minimization)
Objective: \max c^T x Objective: \min b^T y
i-th constraint is \le b_i i-th dual variable y_i \ge 0
i-th constraint is = b_i i-th dual variable y_i is unconstrained
j-th variable x_j \ge 0 j-th constraint is \ge c_j
Strong Duality: If primal has optimal x^*, then dual has optimal y^* and c^T x^* = b^T y^*. Weak Duality: For any feasible x and y, c^T x \le b^T y.
