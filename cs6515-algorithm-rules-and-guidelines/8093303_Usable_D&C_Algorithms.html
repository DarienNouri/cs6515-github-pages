Usable D&C Algorithms

Staff Guidance #65 Divide & Conquer Black-Box Whitelist
Approved course algorithms, reference pseudocode, and standard modifications

For the divide and conquer section, you may use the algorithms presented in the course materials to help you solve presented problems. In cases where differences exist, this post represents the definitive course version.

Black Box Policy & Modification Rules

If a problem does not lend itself directly to one of the standard course algorithms, you may choose to:

  • Leverage divide and conquer techniques directly from scratch, avoiding the use of course algorithms; or,
  • Make modifications to one or more of the approved course algorithms to make it fit the problem at hand.

Modification Requirements: Any modifications made to course algorithms must be clearly described, and the runtime impact of the changes must be accounted for in the runtime analysis.

Approved Algorithms Whitelist: Many divide and conquer algorithms exist beyond what is covered in this course; however, only those explicitly mentioned here may be used. The use of unapproved extracurricular algorithms will result in grading penalties.

1. Binary Search

Search a sorted list for a target key by repeatedly halving the search space.

  • Input:
    • A sorted list of comparable elements $A$.
    • A starting index $s$ (1 is assumed if not provided).
    • An ending index $n$ (length of list assumed if known).
    • The target value $T$.
  • Output: The index of the first encountered match if one exists, or "NOT FOUND" if no match is found.
  • Runtime: $O(\log n)$

Reference Implementation

binary_search(A, s=1, n, T)
    L = s
    R = n
    while L ≤ R do
        m = floor((L + R) / 2)
        if A[m] < T
            L = m + 1
        else if A[m] > T
            R = m − 1
        else
            return m
    return unsuccessful

Common Modifications

  • Finding the leftmost matching value.
  • Finding the rightmost matching value.
  • Finding the insertion point for a missing target value.

2. Merge Sort

Canonical divide-and-conquer sorting algorithm based on DPV pp. 50–51.

  • Input: A list of comparable elements $A$, starting index $s$ (default 1), ending index $n$.
  • Output: The original list, sorted in ascending order.
  • Runtime: $O(n \log n)$

Reference Implementation

merge_sort(A, s=1, n)
    if n > 1
        return merge(merge_sort(A[s ... n/2]),
                     merge_sort(A[n/2 + 1 ... n]))
    else
        return A

merge(L[1 ... i], R[1 ... j])
    if i = 0
        return R
    if j = 0
        return L

    if L[1] ≤ R[1]
        return L[1] + merge(L[2 ... i], R[1 ... j])
    else
        return R[1] + merge(L[1 ... i], R[2 ... j])

Common Modifications

  • Returning the list in descending order.
  • Sorting pairs or tuples $(val, orig\_index)$ to preserve initial array positions.

3. Fast Select (Median of Medians)

Deterministic linear-time selection algorithm based on DC2.12.

  • Input: A list of comparable elements $A$, starting index $s$ (default 1), ending index $n$, and rank integer $k$.
  • Output: The $k$-th smallest element from the original list.
  • Runtime: $O(n)$

Reference Implementation

fast_select(A, s=1, n, k)
    if n = 1
        return A[1]

    i = s
    size = 0
    medians = []

    while (i + 4) ≤ n do
        medians += merge_sort(A, i, i+4)[3]
        size += 1
        i += 5

    if i ≤ n
        medians += merge_sort(A, i, n)[ceil((n - i + 1) / 2)]
        size += 1

    pivot = fast_select(medians, size / 2)

    lows = []
    mids = []
    highs = []

    lowSize = 0
    midSize = 0

    for i = s to n
        if A[i] < pivot
            lows += A[i]
            lowSize += 1
        else if A[i] > pivot
            highs += A[i]
        else
            mids += A[i]
            midSize += 1

    if k ≤ lowSize
        return fast_select(lows, k)
    else if k > lowSize + midSize
        return fast_select(highs, k - lowSize - midSize)
    else
        return pivot

Common Modifications

  • Returning the $k$-th largest element (by setting $k' = n - k + 1$).

4. Fast Multiply (Karatsuba Algorithm)

Sub-quadratic integer multiplication algorithm based on DPV p. 47 and DC1.10.

  • Input: Two $n$-bit integers $x$ and $y$ such that $n = 2^k$.
  • Output: The mathematical product $x \cdot y$.
  • Runtime: $O(n^{\log_2 3}) \approx O(n^{1.585})$

Reference Implementation

fast_multiply(x[1 ... n], y[1 ... n])
    if n = 1
        return x * y

    xl = extract_bits(x, 1, n/2)
    xr = extract_bits(x, n/2 + 1, n)
    yl = extract_bits(y, 1, n/2)
    yr = extract_bits(y, n/2 + 1, n)

    A = fast_multiply(xl, yl)
    B = fast_multiply(xr, yr)
    C = fast_multiply(xl + xr, yl + yr)

    return 2^n * A + 2^(n/2) * (C - A - B) + B

Common Modifications

  • None. Use as an atomic black box for large integer multiplication.

      You don't need to memorize the code necessarily, you need to "memorize" something like this:

      "binary search takes a sorted array A and a target t. You keep two indices, L and R, that define the current search range. Each step you look at the middle index, mid. If A[mid] == t, you return it. If A[mid] < t, you move L to mid + 1; otherwise you move R to mid - 1. This process keeps discarding half the remaining range until it is empty or you find the target." Then you need to know and explain why binary search is O(log n) time.

      That's the basic idea, but like Jamie said, you should know the algorithms above well enough to apply variations to them to solve problems that aren't just a trivial merge sort or binary search. Plus you need to explain what the final runtime is and how you derive it.
