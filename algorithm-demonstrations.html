Longest common subsequence: fill the table, then trace back

Each cell L(i,j) stores the LCS length for two prefixes. A match uses the diagonal plus one; a mismatch chooses the larger of the upper and left cells. Row zero and column zero contain zero. Follow the highlighted dependencies, then trace a valid common subsequence backward from the final cell.

The table fills row by row. Matching characters extend the diagonal solution; mismatches keep the better shorter-prefix solution. Backtracking recovers the characters in reverse order. If several choices tie, different valid longest subsequences may exist.

0/1 knapsack: compare taking and skipping

K(i,b) stores the best value using the first i items with capacity b. Skipping reads K(i−1,b); taking reads the item's value plus K(i−1,b−weight), when it fits. Both choices read the previous row, so each item is available at most once.

Begin with zero items and zero value. Fill capacities for each item using the previous row, then trace backward to identify the selected items. Unlike unbounded knapsack, taking an item cannot reuse the current row.

Read the capacity DP explanation in Week 1.

Merge sort: divide, solve, and combine

Split an array until each subproblem has one element. Merge sorted halves by comparing their front elements. Equal keys come from the left half first, preserving their original order. The recursion has logarithmic depth, and a complete merge level processes all n elements.

One-element arrays are already sorted. Each merge repeatedly chooses the smaller available front item and appends it to the output. The invariant is that this output is sorted and contains precisely the items consumed so far. Merge sort takes O(n log n) time.

Strongly connected components: reverse, finish, discover

Vertices in one SCC can reach each other in both directions. First run DFS on the reversed graph and record finishing order. Then run DFS on the original graph in decreasing reversed-graph finishing order. Each new DFS tree discovers one component; collapsing those components produces a DAG.

Reverse every edge, perform a full DFS forest, and record each vertex as it finishes. Return to the original graph and process the reversed finishing order. An unvisited start vertex begins the next SCC. Edges between distinct components form the acyclic condensation graph.

Linear programming: feasible regions and objective lines

In this bounded example, x and y are nonnegative, x ≤ 4, y ≤ 3, and x+y ≤ 5. Add constraints to see their intersection, inspect its vertices, and move a linear objective line to the best feasible value.

The feasible polygon has vertices (0,0), (4,0), (4,1), (2,3), and (0,3). Maximizing 2x+y gives value 9 at (4,1). Maximizing x+y instead gives value 5 along the entire edge from (4,1) to (2,3), illustrating that an LP optimum need not be unique.
